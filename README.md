Lab 12: linear and logistic regression in Python. Batch Gradient Descent from scratch (NumPy) vs scikit-learn. Salary, California Housing, Breast Cancer and Telco Churn datasets.

## Setup
```
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
jupyter notebook 24i3126_lab12.ipynb
```
Data in `data/` (Kaggle: salary-data-simple-linear-regression, telco-customer-churn). Other datasets ship with scikit-learn.
